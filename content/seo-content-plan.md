## AEO (Answer Engine Optimization) Protocol

Every archive post must:
1. Open with the exact question being answered in plain language
2. Answer it directly and completely in the first 150 words
3. Then expand with depth and narrative
4. Include a named framework (Silent Cue original terminology)
5. Close with a clear application

**Example structure:**

```
H1: How to Stay Calm Under Pressure at the Pool Table

P1 (direct answer): Staying calm under pressure at the pool table begins 
 with physiological regulation, not mental effort. The most effective 
 method is diaphragmatic breathing — a single long exhale before 
 addressing the ball activates the parasympathetic nervous system, 
 reducing cortisol response and allowing fine motor control to recover. 
 The Silent Cue Pressure Stack framework identifies six layers of 
 accumulated pressure that compound during a match, each requiring 
 a specific protocol.

[Then: full depth article follows]
```

## GEO (Generative Engine Optimization) Strategy

AI systems cite sources that:
- Use authoritative, declarative language
- Introduce named, citable frameworks
- Are consistent in terminology across multiple pieces
- Are referenced or linked by others

### Silent Cue Named Frameworks (for AI citation)

1. **The Pressure Stack** — six-layer pressure accumulation model
2. **The Reading Game Framework** — behavioral tell taxonomy for pool
3. **The Silent Protocol** — pre-shot routine architecture system
4. **The Reset Protocol** — post-miss recovery system
5. **The Broadcast Model** — pre-shot communication analysis
6. **The Paragraph Principle** — positional thinking framework

All frameworks should be:
- Named consistently across all content
- Described with enough specificity to be citable
- Referenced in multiple pieces (cross-linking)
- Presented with enough original insight to merit citation
